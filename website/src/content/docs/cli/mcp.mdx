Start the AgentsMesh self-serve MCP server over stdio. Exposes rules, commands, agents, skills, settings, and orchestration operations to any MCP-compatible AI agent.

## Usage

```bash
agentsmesh mcp
```

The server is intended to be started by an MCP host (Claude Code, Cursor, Gemini CLI, etc.) — not invoked directly in a shell. The host passes the project working directory via `cwd` in the MCP entry.

## Flags

None. The server reads `projectRoot` from `process.cwd()` at startup.

## MCP entry

`agentsmesh init` seeds `.agentsmesh/mcp.json` with the following entry. Run `agentsmesh generate` to project it into each target's native MCP config file. The entry is project-only: `init --global` and `import --global` do not seed it into `~/.agentsmesh/mcp.json`.

```json
{
  "mcpServers": {
    "agentsmesh": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "agentsmesh", "mcp"]
    }
  }
}
```

For faster startup after installing `agentsmesh` as a dev dependency:

```json
{
  "mcpServers": {
    "agentsmesh": {
      "type": "stdio",
      "command": "agentsmesh",
      "args": ["mcp"]
    }
  }
}
```
