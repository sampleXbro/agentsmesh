The AgentsMesh MCP server is now added only at project level. Before, `agentsmesh init --global` and `agentsmesh import --global` also put the `agentsmesh` entry into `~/.agentsmesh/mcp.json`, so `generate --global` wrote it into every tool's global MCP config (for example `~/.claude.json`) and the server started in every folder, also in folders without AgentsMesh. Now `init --global` scaffolds `~/.agentsmesh/mcp.json` with its `mcpServers` key commented out, so `generate --global` does not touch the MCP servers in your tools' global config until servers are listed there, in an installed pack or in an `extends` source, and `import --global` no longer adds the entry. Project `init` and `import` still add it as before, except in your home folder, whose `.agentsmesh` is the global config. An entry that an older `init --global` added stays and keeps working; nothing changes until you edit it. To remove it: if `~/.agentsmesh/mcp.json` lists other servers too, delete the `agentsmesh` entry and run `agentsmesh generate --global`, which removes it from every tool. If it was the only server, delete the whole `mcpServers` key instead (an empty `"mcpServers": {}` makes Claude Code, Zed and Goose clear every global MCP server, also ones you added in the tool), then delete the `agentsmesh` server from each tool's global MCP config by hand, for example `~/.claude.json`, `~/.cursor/mcp.json` or `~/.codex/config.toml`. Delete it from your tools before you run `agentsmesh import --global` too, or the import copies it back.
