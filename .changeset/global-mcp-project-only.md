The AgentsMesh MCP server is now added only at project level. Before, `agentsmesh init --global` and `agentsmesh import --global` also put the `agentsmesh` entry into `~/.agentsmesh/mcp.json`, so `generate --global` wrote it into every tool's global MCP config (for example `~/.claude.json`) and the server started in every folder, also in folders without AgentsMesh. Now `init --global` scaffolds `~/.agentsmesh/mcp.json` with its `mcpServers` key commented out, so `generate --global` does not touch the MCP servers in your tools' global config until servers are listed there or in an installed pack, and `import --global` no longer adds the entry. Project `init` and `import` still add it as before. An entry that an older `init --global` added stays and keeps working; nothing changes until you edit it. To remove it, delete the `agentsmesh` entry from `~/.agentsmesh/mcp.json`. If it was the only server, delete the whole `mcpServers` key instead: an empty `"mcpServers": {}` tells some tools (Claude Code, Zed, Goose) to clear every global MCP server, also ones you added in the tool. Then delete the `agentsmesh` server from each tool's global MCP config (for example `~/.claude.json`, `~/.cursor/mcp.json`, `~/.codex/config.toml`), because most tools keep a server that is no longer in `~/.agentsmesh/mcp.json`.
